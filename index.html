AI-powered Bible knowledge graph for exploring verses, themes, people, and biblical connections.

About the project

AI-powered Bible exploration + full-stack development

Scripture Graph explores the Bible as an interconnected network. Users can search a verse, person, topic, or question, then compare two searches to see shared ideas and differences in emphasis. They can save Scripture to named study collections, add personal notes, and export a notebook. The app combines a JavaScript/Cytoscape frontend with a Flask backend, external Bible data, and AI-assisted explanations grounded in retrieved passages.

wrdly

View projectView code

A mobile word game with unlimited rounds, customizable word lengths, and animated feedback.

About the project

Your word. Your pace.

I built wrdly, a React Native and Expo mobile word game that lets players choose between four- and eight-letter English words and play as many rounds as they want. Players have six guesses, with tiles that flip one at a time to reveal green, yellow, or gray feedback. The app saves games played and won on the phone using AsyncStorage. I used Codex to help turn my spec into a working app, then tested it in Expo Go, refined the keyboard and animations, and used an independent AI code review to guide further fixes.

React NativeExpoTypeScriptAsyncStorageAI-Assisted Development

Mobile App Redesign

View full project

AI-assisted usability redesign of Pittsburgh’s mobile parking experience.

About the project

Reducing friction without adding new features

For this team project, we analyzed Go Mobile PGH and redesigned its structure to make everyday parking faster and less error-prone using AI. The challenge was to improve usability without inventing new functionality. Our prototype condensed the core parking flow from seven screens to one primary screen by intelligently pre-filling existing information, while still letting users review and edit every detail. We also considered feasibility, transparency, accountability, fairness, and privacy in the proposed AI-assisted experience.

HCIAI Product DesignInteraction DesignUsabilityFATE Analysis

Weather Activity Recommendation App

View live projectView code

Interactive web app that uses live weather and nearby place data to recommend things to do.

About the project

Weather-based planning with public APIs

I built an interactive website that helps users decide what to do based on their location, current weather, travel distance, activity preference, and whether they want to be indoors or outdoors. The project uses public weather, geocoding, and place APIs to turn a location into coordinates, retrieve live weather data, search for nearby places, and rank recommendations. I also added error handling and fallback services so the app can respond more clearly when an API is slow or unavailable.

Opportunity Radar

Explore projectView code

Semantic job discovery, resume connections, and application tracking with a persistent vector database.

About the project

Find opportunities by meaning

Opportunity Radar collects real public company job postings and searches their descriptions by meaning using persistent ChromaDB embeddings. It separates resume similarity from eligibility, shows original source passages and freshness, and keeps a personal application tracker. The frontend connects to a locally running or separately hosted Python backend.
